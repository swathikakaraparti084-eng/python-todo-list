
Python To-Do List

About

This is a simple To-Do List application built using Python. It helps users organize and manage their daily tasks.

Features

- Add new tasks
- View tasks
- Organize daily activities

Technologies Used

- Python
- Visual Studio Code

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

python todo.py

Future Improvements

- Delete tasks
- Mark tasks as completed
- Save tasks to a file
